# ใช้ AI สร้างหรือแก้ dashboard

คู่มือสำหรับทีม operate ใช้ AI เพิ่มแท็บ dashboard ใหม่ หรือแก้แท็บเดิม โดยไม่ต้องเขียนโค้ดเอง

## ภาพรวม flow

1. **เตรียมโจทย์**: dashboard นี้ใช้ตอบคำถามอะไร, ใช้ไฟล์ CSV แบบไหน, อยากเห็นอะไรบนหน้า และหน้าตาประมาณไหน (แนบรูปหรือภาพหน้าจอตัวอย่างได้)
2. **สั่ง AI**: เลือกแบบ A หรือ B ด้านล่าง แล้ว copy prompt ไปเติมช่อง `[...]`
3. **ตรวจผล**: ทำตาม "เช็กลิสต์ตรวจงาน" ท้ายไฟล์
4. **ส่งเข้าระบบ**: commit แล้ว push ขึ้น `main` Vercel จะ deploy ให้เอง ต้อง commit ด้วยบัญชี GitHub **phonphai** เท่านั้น เพราะ Vercel แผน Hobby ไม่ deploy commit ของบัญชีอื่น

## Prompt สำหรับ AI ที่ทำงานในโฟลเดอร์

เปิดโปรเจกต์ใน AI ที่ทำงานในโฟลเดอร์ (เช่น Claude Code) แล้ว copy prompt นี้ไปใช้ ข้อความนี้คือแม่แบบ

```
เพิ่มแท็บ dashboard ใหม่ชื่อ "ศูนย์พักพิง"
ชุดข้อมูล: ไฟล์ชนิดใหม่ "รายงานศูนย์พักพิงชั่วคราว" ตัวอย่างอยู่ที่ docs/demo/shelters_demo.csv
  ให้เพิ่มชุดข้อมูลใหม่ id "shelters" ตาม README หัวข้อ "เพิ่มชุดข้อมูลใหม่" และ copy ไฟล์นี้ไปเป็นข้อมูลตั้งต้น data/shelters.csv
ต้องการเห็น:
- การ์ดตัวเลขของวันล่าสุดในไฟล์: ผู้พักพิง, ศูนย์ที่ยังเปิด, อัตราการใช้พื้นที่ (ผู้พักพิง ÷ ความจุของศูนย์ที่เปิด), ผู้สูงอายุ / เด็ก / ผู้พิการ
- กราฟเส้นจำนวนผู้พักพิงรวมรายวัน พร้อมบอกวันที่มีผู้พักพิงสูงสุด
- กราฟแท่งผู้พักพิงวันล่าสุดแยกจังหวัด
- ตารางศูนย์พักพิงทุกแห่ง ใช้รายงานล่าสุดของแต่ละศูนย์: ชื่อศูนย์, จังหวัด, ความจุ, ผู้พักพิง, แถบอัตราการใช้พื้นที่, สถานะ เปิด/ปิด ศูนย์ที่ใช้พื้นที่ตั้งแต่ 80% ขึ้นไปให้เน้นสี
- อาหารที่แจกรวมทั้งช่วง (มื้อ)
เงื่อนไขของข้อมูล: evacuees เป็นยอดคงค้างรายวัน ให้ใช้ค่าของวันล่าสุด ห้ามบวกทุกวัน ส่วน meals_served บวกรวมได้
  อัปโหลดหลายไฟล์ที่เป็นคนละช่วงวันที่ (เช่น docs/demo/shelters_demo_part2.csv) ต้องรวมกันได้
หน้าตา: ออกแบบเอง ไม่ต้องมีแผนที่ ใช้โทนสีเขียวอมฟ้าให้ต่างจากแท็บอื่น อ่านง่ายบนมือถือ
แถบด้านบน (แท็บ, อัปโหลด CSV, แชร์, ประวัติการแชร์) ให้คงไว้ตามเดิม หน้าใหม่ต้องไม่มีปุ่มเหล่านี้เอง และรับข้อมูลด้วย receiveCSV ตามหัวข้อ "โครงหน้าที่ตายตัว" ใน AGENTS.md
ทำตาม AGENTS.md และตรวจงานตามหัวข้อ "ตรวจงานก่อนส่ง" ให้ครบ แล้วสรุปตัวเลขที่ตรวจเทียบกับ CSV ให้ดู
```

## Prompt สำหรับ AI แบบแชทบนเว็บ

AI บนเว็บแก้ไฟล์ในโปรเจกต์ให้ไม่ได้ prompt นี้จึงสั่งให้ส่ง**ไฟล์ฉบับเต็ม**ทุกไฟล์ที่ต้องเปลี่ยนกลับมา เราแค่บันทึกทับไฟล์เดิม ไม่ต้องหาบรรทัดเอง

1. แนบไฟล์ 5 ไฟล์
   - `AGENTS.md`
   - `dashboards/shared/csv.js` (ให้ AI ใช้อ้างอิง ไม่ต้องแก้)
   - `api/_datasets.js`
   - `index.html`
   - `docs/demo/shelters_demo.csv`
2. ใช้ prompt ตัวอย่างนี้ <ปรับเปลี่ยนตามต้องการ>

```
ไฟล์ที่แนบ: กฎของโปรเจกต์ (AGENTS.md), ฟังก์ชันอ่าน CSV และระบบรับข้อมูล (csv.js ใช้อ้างอิง ไม่ต้องแก้), รายการชุดข้อมูลฝั่ง API (_datasets.js), แถบแท็บ (index.html) และข้อมูลตัวอย่าง (shelters_demo.csv)
ช่วยเขียน dashboard ใหม่ชื่อแท็บ "ศูนย์พักพิง" จากไฟล์ชนิดใหม่ "รายงานศูนย์พักพิงชั่วคราว" (ไฟล์ที่แนบ)

ข้อมูล:
- แถวหัวคอลัมน์ขึ้นต้นด้วย date มีหัวรายงาน 2 บรรทัดก่อนหน้า (บรรทัดที่ 2 คือช่วงวันที่ภาษาไทย)
- 1 แถว = รายงานประจำวันของศูนย์พักพิง 1 แห่ง
- evacuees เป็นยอดคงค้างรายวัน ให้ใช้ค่าของวันล่าสุด ห้ามบวกทุกวัน ส่วน meals_served บวกรวมได้
- อัปโหลดหลายไฟล์ที่เป็นคนละช่วงวันที่ต้องรวมกันได้

ต้องการเห็น:
- การ์ดตัวเลขของวันล่าสุด: ผู้พักพิง, ศูนย์ที่ยังเปิด, อัตราการใช้พื้นที่ (ผู้พักพิง ÷ ความจุของศูนย์ที่เปิด), ผู้สูงอายุ / เด็ก / ผู้พิการ
- กราฟเส้นผู้พักพิงรวมรายวัน พร้อมบอกวันที่สูงสุด
- กราฟแท่งผู้พักพิงวันล่าสุดแยกจังหวัด
- ตารางศูนย์พักพิงทุกแห่ง (รายงานล่าสุดของแต่ละศูนย์): ชื่อ, จังหวัด, ความจุ, ผู้พักพิง, แถบอัตราการใช้พื้นที่, สถานะ เปิด/ปิด และเน้นสีศูนย์ที่ใช้ตั้งแต่ 80%
- อาหารที่แจกรวมทั้งช่วง (มื้อ)
หน้าตา: ออกแบบเอง ไม่ต้องมีแผนที่ โทนสีเขียวอมฟ้า อ่านง่ายบนมือถือ

เงื่อนไข:
- ทำตามหัวข้อ "โครงหน้าที่ตายตัว" และ "ข้อกำหนดของทุกหน้า dashboard" ใน AGENTS.md
- เป็นไฟล์ HTML ไฟล์เดียว CSS และ JS อยู่ในไฟล์ ห้ามมีปุ่มอัปโหลด ปุ่มแชร์ ปุ่มประวัติ หรือ <input type="file">
- โหลด <script src="shared/csv.js"></script> แล้วรับข้อมูลด้วย receiveCSV(apply, 'shelters')
  apply(files, label) ได้ไฟล์ทั้งหมดเป็น [{name, text}] ใช้ parseCSV, splitHeader(rows, 'date'), toNum, mergePeriods จาก csv.js
  ถ้าไฟล์ผิดชนิด (ไม่พบหัวคอลัมน์ date หรือขาดคอลัมน์) ให้ throw ข้อความภาษาไทยที่บอกชื่อไฟล์ ก่อนเปลี่ยนหน้า
- ใส่ค่าจาก CSV ลงหน้าด้วย textContent

ส่งกลับมาให้ครบ 4 อย่าง โดยไฟล์ทุกไฟล์ต้องเป็นฉบับเต็มที่บันทึกทับของเดิมได้ทันที:
1. ไฟล์ใหม่ dashboards/shelters.html ฉบับเต็ม
2. ไฟล์ api/_datasets.js ฉบับเต็ม ที่เพิ่มแค่ 1 บรรทัดใน DATASETS: shelters: { headerFirstColumn: 'date' },
   ห้ามแก้ ลบ หรือจัดรูปแบบบรรทัดอื่น รวมถึงคอมเมนต์ (บรรทัดที่ขึ้นต้นด้วย //)
3. ไฟล์ index.html ฉบับเต็ม ที่เพิ่มแค่ 1 บรรทัดใน DASHBOARDS: { id: 'shelters', title: 'ศูนย์พักพิง', file: 'dashboards/shelters.html' },
   ห้ามแก้ ลบ หรือจัดรูปแบบบรรทัดอื่น รวมถึงคอมเมนต์ (บรรทัดที่ขึ้นต้นด้วย //)
4. ตัวเลขที่ควรเห็นบนหน้าเมื่อใช้ไฟล์ที่แนบ คำนวณจากข้อมูลในไฟล์จริงๆ
ไม่ต้องแก้ csv.js ระบบจะใช้ไฟล์ตั้งต้น data/shelters.csv ตามชื่อชุดข้อมูลเอง
```

3. นำผลลัพธ์ไปวาง
   - บันทึกข้อ 1 เป็น `dashboards/shelters.html` (ไฟล์ใหม่)
   - บันทึกข้อ 2 ทับ `api/_datasets.js` และข้อ 3 ทับ `index.html`
   - copy `docs/demo/shelters_demo.csv` ไปไว้ที่ `data/shelters.csv` (ชื่อไฟล์ต้องตรงกับ id ชุดข้อมูล)
