# ใช้ AI สร้างหรือแก้ dashboard

คู่มือสำหรับทีม operate ใช้ AI เพิ่มแท็บ dashboard ใหม่ หรือแก้แท็บเดิม โดยไม่ต้องเขียนโค้ดเอง

## ภาพรวม flow

1. **เตรียมโจทย์**: dashboard นี้ใช้ตอบคำถามอะไร, ใช้ไฟล์ CSV แบบไหน, อยากเห็นอะไรบนหน้า และหน้าตาประมาณไหน (แนบรูปหรือภาพหน้าจอตัวอย่างได้)
2. **สั่ง AI**: เลือกแบบ A หรือ B ด้านล่าง แล้ว copy prompt ไปเติมช่อง `[...]`
3. **ตรวจผล**: ทำตาม "เช็กลิสต์ตรวจงาน" ท้ายไฟล์
4. **ส่งเข้าระบบ**: commit แล้ว push ขึ้น `main` Vercel จะ deploy ให้เอง ต้อง commit ด้วยบัญชี GitHub **phonphai** เท่านั้น เพราะ Vercel แผน Hobby ไม่ deploy commit ของบัญชีอื่น

## เลือกแบบที่จะใช้

| | แบบ A: AI ที่ทำงานในโฟลเดอร์โปรเจกต์ | แบบ B: AI แบบแชทบนเว็บ |
|---|---|---|
| ตัวอย่าง | Claude Code, Cursor, Codex, GitHub Copilot | ChatGPT, Claude, Gemini บนเว็บ |
| AI รู้กฎของโปรเจกต์ | อ่าน `AGENTS.md` เอง | ต้องแนบไฟล์ให้ |
| AI แก้ไฟล์และทดสอบ | ทำเองได้ | เราต้อง copy ผลมาใส่ไฟล์และทดสอบเอง |
| แนะนำ | ✔ ใช้แบบนี้ถ้ามี | ใช้เมื่อไม่มีแบบ A |

> **ข้อมูลจริงอาจมีข้อมูลส่วนบุคคลหรือข้อมูลภายใน** การแนบไฟล์ให้ AI บนเว็บคือการส่งข้อมูลออกไปภายนอก ให้แนบ `source/md_flood_report_test.csv` หรือตัดเหลือไม่กี่แถวแทนไฟล์จริง

## แบบ A: AI ที่ทำงานในโฟลเดอร์โปรเจกต์

เปิดโฟลเดอร์โปรเจกต์ใน AI นั้น แล้วใช้ prompt ตามงาน

### เพิ่มแท็บใหม่

```
เพิ่มแท็บ dashboard ใหม่ชื่อ "[ชื่อแท็บ]"
ข้อมูล: ใช้ข้อมูลชุดเดียวกับแท็บอื่น (รายงานจำนวนคำร้องและความเสียหาย ตัวอย่าง data/md_flood_report.csv)
ต้องการเห็น:
- [เช่น จำนวนคำร้องแยกตามภาค เป็นกราฟแท่ง]
- [เช่น 10 จังหวัดที่ช่วยเหลือได้น้อยที่สุด (ร้อยละ) เป็นตาราง]
- [เช่น การ์ดตัวเลข: คำร้องทั้งหมด, ครัวเรือนได้รับผลกระทบ]
เฉพาะแถว: [เช่น disaster = วาตภัย / ทุกแถว]
หน้าตา: [การ์ด + ตาราง แบบ _template.html / ออกแบบเองแบบ disasters.html / ตามรูปที่แนบ]
ทำตาม AGENTS.md และตรวจงานตามหัวข้อ "ตรวจงานก่อนส่ง" ให้ครบ แล้วสรุปตัวเลขที่ตรวจเทียบกับ CSV ให้ดู
```

### แก้แท็บเดิม

```
แท็บ "[ชื่อแท็บ]" ([dashboards/ชื่อไฟล์.html]) ต้องการ [สิ่งที่อยากเปลี่ยน เช่น เพิ่มกราฟคำร้องรายภาคใต้ตัวเลขด้านบน]
ส่วนอื่นของหน้าให้คงเดิม ทำตาม AGENTS.md และตรวจงานตามหัวข้อ "ตรวจงานก่อนส่ง"
```

### แจ้งปัญหา

```
แท็บ "[ชื่อแท็บ]" มีปัญหา: [อาการ เช่น อัปโหลดไฟล์ X แล้วคำร้องรวมขึ้น 1,000 แต่ใน CSV รวมได้ 1,200]
ไฟล์ที่ใช้ทดสอบ: [ชื่อไฟล์]
หาสาเหตุ แก้ แล้วตรวจงานตาม AGENTS.md
```

## แบบ B: AI แบบแชทบนเว็บ

1. แนบไฟล์เหล่านี้ในแชท
   - `AGENTS.md` (กฎของโปรเจกต์)
   - `dashboards/shared/csv.js` (ฟังก์ชันอ่าน CSV ที่ต้องใช้)
   - `dashboards/disasters.html` (ตัวอย่างหน้าที่ออกแบบเอง)
   - ไฟล์ CSV ตัวอย่าง (ไฟล์ทดสอบ ไม่ใช่ไฟล์จริง ดูคำเตือนด้านบน)
   - รูปตัวอย่างหน้าตาที่อยากได้ (ถ้ามี)
2. ใช้ prompt นี้

```
ไฟล์ที่แนบคือกฎของโปรเจกต์ (AGENTS.md), ฟังก์ชันอ่าน CSV (csv.js), ตัวอย่าง dashboard (disasters.html) และข้อมูลตัวอย่าง
ช่วยเขียน dashboard ใหม่เป็นไฟล์ HTML ไฟล์เดียว ชื่อไฟล์ dashboards/[ชื่อไฟล์].html
ชื่อแท็บ: "[ชื่อแท็บ]"
ต้องการเห็น:
- [...]
- [...]
หน้าตา: [อธิบาย หรือ "ตามรูปที่แนบ"]
เงื่อนไข:
- ทำตามหัวข้อ "ข้อกำหนดของทุกหน้า dashboard" ใน AGENTS.md
- โหลด csv.js ด้วย <script src="shared/csv.js"></script> และเชื่อมข้อมูลด้วย connectCSV(input, apply) จากไฟล์นั้น (ได้ข้อมูลล่าสุด การอัปโหลด และปุ่มแชร์ให้เอง)
- ส่งไฟล์ HTML ฉบับเต็ม พร้อมบรรทัดที่ต้องเพิ่มใน DASHBOARDS ของ index.html
- บอกตัวเลขที่ควรเห็นบนหน้าเมื่ออัปโหลดไฟล์ CSV ตัวอย่างที่แนบ คำนวณจากข้อมูลในไฟล์จริงๆ
```

3. บันทึกไฟล์ที่ได้ไว้ใน `dashboards/` แล้วเพิ่มบรรทัดใน `DASHBOARDS` ของ `index.html`
4. ทำ "เช็กลิสต์ตรวจงาน" ด้านล่างเอง ถ้าไม่ผ่าน ให้ copy ข้อความ error หรืออาการกลับไปบอก AI ในแชทเดิม

## เช็กลิสต์ตรวจงาน

ไฟล์ทดสอบใน `source/` ไม่ได้อยู่ใน git ถ้าในเครื่องไม่มี ให้ขอจากทีมก่อน

- [ ] เปิด `index.html` แล้วมีแท็บใหม่ กดสลับไปมาได้ และข้อมูลที่อัปโหลดไว้ในแต่ละแท็บไม่หาย
- [ ] เปิดผ่าน `python3 -m http.server` แล้วแท็บใหม่แสดงข้อมูลตั้งต้นทันที อัปโหลดแล้วรีเฟรช ต้องกลับเป็นข้อมูลตั้งต้น
- [ ] บนมือถือยังเห็นบรรทัดบอกที่มาของข้อมูล ("ข้อมูลล่าสุด แชร์เมื่อ …" หรือ "ข้อมูลตั้งต้น …")
- [ ] อัปโหลด `source/md_flood_report.csv` แล้วตัวเลขตรงกับที่ AI บอก และสุ่มเทียบกับ Excel 1–2 ค่า
- [ ] อัปโหลด `md_flood_report_part1.csv` + `md_flood_report_part2.csv` พร้อมกัน แล้วได้ตัวเลขเท่ากับข้อที่แล้ว
- [ ] อัปโหลดไฟล์ CSV อื่นที่ไม่ใช่รายงาน แล้วมีข้อความแจ้งเตือน และตัวเลขเดิมยังอยู่
- [ ] ย่อหน้าต่างให้แคบเท่ามือถือ แล้วอ่านได้ ไม่ต้องเลื่อนซ้ายขวาทั้งหน้า
- [ ] แท็บเดิมยังทำงานเหมือนเดิม
- [ ] หลัง deploy บน Vercel: อัปโหลดแล้วมีปุ่ม "แชร์" สีเขียวขึ้นข้างปุ่มอัปโหลด ทดลองแชร์ แล้วเปิดเว็บใน browser อื่นต้องเห็นข้อมูลชุดนั้น (หลังทดสอบเสร็จ ให้แชร์ไฟล์จริงกลับไปด้วย)
