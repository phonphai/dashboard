# คู่มือใช้งาน Dashboard พ้นภัย

คู่มือสำหรับ **ผู้บริหาร** (ดูข้อมูล) และ **ทีมกรม** (อัปเดตข้อมูลรายวัน) ไม่ต้องมีความรู้ด้านเทคนิค
ขอลิงก์เว็บได้จากทีม operate (ถ้าระบบตั้งรหัสผ่านสำหรับแชร์ไว้ ทีมกรมขอรหัสจากทีม operate ด้วย)

## ข้อมูลบนหน้าเป็นของวันไหน

ทุกแท็บมี 2 จุดที่ควรดู:

- **"ข้อมูล ณ ช่วงวันที่ …"** ใต้หัวข้อใหญ่: ช่วงวันที่ของรายงาน อ่านมาจากไฟล์ CSV
- **บรรทัดข้างปุ่มอัปโหลด CSV:** บอกว่ากำลังดูข้อมูลชุดไหน

| ข้อความที่เห็น | ความหมาย |
|---|---|
| `ข้อมูลล่าสุด แชร์เมื่อ 5 พ.ย. 2569 09:30 · ชื่อไฟล์` | ข้อมูลที่ทีมกรมแชร์ล่าสุด ทุกคนเห็นชุดเดียวกัน |
| `ข้อมูลตั้งต้น · ชื่อไฟล์` | ยังไม่เคยมีการแชร์ หรือระบบแชร์มีปัญหา (แจ้งทีม operate) |
| `ชื่อไฟล์ · ตัวอย่าง ยังไม่ได้แชร์` | ไฟล์ที่คุณอัปโหลดเอง คนอื่นไม่เห็น รีเฟรชหน้าแล้วกลับไปเป็นข้อมูลล่าสุด |

## สำหรับผู้บริหาร: ดูข้อมูล

1. เปิดลิงก์เว็บ แล้วเลือกแท็บด้านบน
   - **อุทกภัยรายจังหวัด:** ตัวเลขสรุป แผนที่จังหวัดที่ได้รับผลกระทบ และตารางรายจังหวัด
   - **สรุปคำร้องทุกประเภทภัย:** กราฟคำร้องตามประเภทภัยและภาค การช่วยเหลือ ความเสียหาย และ 10 จังหวัดที่มีคำร้องมากที่สุด
2. แท็บอุทกภัย: ชี้หรือแตะจังหวัดบนแผนที่เพื่อดูตัวเลข หรือกดแถวในตารางเพื่อดูว่าจังหวัดนั้นอยู่ตรงไหนบนแผนที่ บนมือถือเลือกจังหวัดจากรายการได้
3. แท็บทุกประเภทภัย: ชี้หรือแตะแท่งกราฟเพื่อดูตัวเลข ตัวเลขทั้งหมดมีในตารางท้ายหน้าด้วย
4. เปิดจากมือถือได้ หน้าจะจัดรูปแบบให้อ่านง่ายเอง

ถ้าเปิดหน้าค้างไว้นาน ให้**รีเฟรช**เพื่อดูข้อมูลที่แชร์ใหม่ ผู้บริหารไม่ต้องกดอัปโหลด ถ้าเผลออัปโหลดไป ให้รีเฟรชหน้า

## สำหรับทีมกรม: อัปเดตข้อมูลรายวัน

ใช้ไฟล์ export **"รายงานจำนวนคำร้องและความเสียหาย"** จากระบบพ้นภัย ไม่ต้องแก้ไฟล์ก่อนอัปโหลด

1. เปิดลิงก์เว็บ จะอยู่แท็บไหนก็ได้ เพราะทุกแท็บใช้ข้อมูลชุดเดียวกัน
2. กด **อัปโหลด CSV** แล้วเลือกไฟล์ ถ้ามีหลายไฟล์ ให้กด Ctrl (บน Mac ใช้ Cmd) ค้างไว้แล้วคลิกเลือกทุกไฟล์ในหน้าต่างเดียว
3. **ตรวจข้อมูลก่อนแชร์:** ข้างปุ่มจะขึ้นว่า "ตัวอย่าง ยังไม่ได้แชร์" ตอนนี้มีแค่คุณที่เห็น ให้ดูช่วงวันที่ และเทียบยอดรวม 1–2 ค่ากับไฟล์ใน Excel
4. กดปุ่ม **แชร์** (สีเขียว) ตรวจชื่อไฟล์ในหน้าต่างยืนยัน แล้วกด **แชร์** ถ้าระบบตั้งรหัสผ่านไว้ จะมีช่องให้ใส่รหัสขึ้นมา
5. เมื่อขึ้นข้อความ "แชร์แล้ว" ข้างปุ่มจะเปลี่ยนเป็น "ข้อมูลล่าสุด แชร์เมื่อ …" ผู้บริหารจะเห็นข้อมูลชุดนี้ในทุกแท็บเมื่อเปิดหรือรีเฟรชหน้า ภายในไม่เกิน 1 นาทีหลังแชร์

ควรรู้:
- **แชร์แต่ละครั้งแทนที่ข้อมูลเดิมทั้งหมด** ไม่ได้ต่อท้าย ถ้ารายงานแบ่งเป็นหลายไฟล์ ต้องเลือกทุกไฟล์พร้อมกันในการอัปโหลดครั้งเดียว
- **อย่าเลือกไฟล์ที่มีข้อมูลซ้ำกัน** เช่น ไฟล์เต็มกับไฟล์บางส่วนของวันเดียวกัน ตัวเลขจะถูกนับซ้ำ
- **ถ้าแชร์ไฟล์ผิด** ให้อัปโหลดไฟล์ที่ถูกต้องแล้วแชร์ซ้ำ ชุดใหม่จะแทนที่ทันที ระบบเก็บประวัติทุกครั้งไว้ให้ทีม operate ตรวจย้อนหลังได้
- **ถ้าอัปโหลดผิดแต่ยังไม่ได้กดแชร์** รีเฟรชหน้าได้เลย ไม่มีผลกับคนอื่น
- **ทุกคนที่เปิดเว็บกดแชร์ได้** (ถ้าไม่ได้ตั้งรหัสผ่าน) ผู้บริหารและคนอื่นจึงไม่ควรกดปุ่มสีเขียว ถ้ามีรหัสผ่าน อย่าส่งต่อ และถ้าคิดว่ารหัสหลุด ให้แจ้งทีม operate เปลี่ยนรหัส

## ปัญหาที่พบบ่อย

| อาการ / ข้อความ | สาเหตุ | ทำอย่างไร |
|---|---|---|
| ไม่พบแถวหัวคอลัมน์ "province" | ไม่ใช่ไฟล์รายงานนี้ หรือหัวคอลัมน์ถูกแก้ | export รายงานใหม่จากระบบ แล้วอัปโหลดโดยไม่แก้ไฟล์ |
| ไม่พบคอลัมน์ … | ไฟล์มีคอลัมน์ไม่ครบ | export รายงานใหม่ ถ้ายังเป็นอยู่ แจ้งทีม operate พร้อมชื่อคอลัมน์ที่ขึ้น |
| ไม่พบแถวที่ disaster = "อุทกภัย" (แท็บอุทกภัย) | ไฟล์นั้นไม่มีข้อมูลอุทกภัย | ตรวจว่าเลือกไฟล์ถูกต้อง หรืออัปโหลดจากแท็บทุกประเภทภัยแทน |
| ต้องใส่รหัสผ่าน / รหัสผ่านไม่ถูกต้อง (ในหน้าต่างแชร์) | ระบบตั้งรหัสไว้ หรือพิมพ์รหัสผิด | ใส่รหัสในช่องแล้วกดแชร์ ถ้าไม่มีรหัส ให้ขอจากทีม operate |
| แชร์ไม่สำเร็จ: … ไม่ใช่ไฟล์รายงานจำนวนคำร้องและความเสียหาย | ไฟล์ไม่ใช่รายงานนี้ | export รายงานใหม่จากระบบ แล้วอัปโหลดอีกครั้ง |
| ปุ่มแชร์ใช้ได้เฉพาะบนเว็บที่ deploy บน Vercel | เปิดจากไฟล์ในเครื่อง ไม่ได้เปิดจากลิงก์เว็บ | เปิดจากลิงก์เว็บแล้วทำใหม่ |
| อ่านข้อมูลที่แชร์ไม่ได้ / แชร์ไม่สำเร็จด้วยข้อความอื่น | ระบบแชร์ยังตั้งค่าไม่ครบหรือมีปัญหา | แจ้งทีม operate พร้อมข้อความที่ขึ้น |
| ผู้บริหารยังเห็นข้อมูลเก่า | เปิดหน้าค้างไว้ก่อนแชร์ หรือเพิ่งแชร์ไม่ถึง 1 นาที | รอสักครู่แล้วรีเฟรชหน้า จากนั้นดูเวลาที่แชร์ข้างปุ่มอัปโหลด |
| ขึ้น "ข้อมูลตั้งต้น" ทั้งที่เคยแชร์แล้ว | ระบบแชร์มีปัญหา | แจ้งทีม operate |
| แผนที่ไม่ขึ้น | อินเทอร์เน็ตมีปัญหา | กด "ลองโหลดแผนที่อีกครั้ง" หรือรีเฟรช ตัวเลขและตารางยังใช้ได้ตามปกติ |
| ตัวเลขสูงผิดปกติ เช่น เกือบ 2 เท่า | เลือกไฟล์ที่ข้อมูลซ้ำกัน | อัปโหลดใหม่โดยเลือกเฉพาะไฟล์ที่ไม่ซ้ำ แล้วแชร์ซ้ำ |
