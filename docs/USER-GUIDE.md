# คู่มือใช้งาน Dashboard พ้นภัย

คู่มือสำหรับ **ผู้บริหาร** (ดูข้อมูล) และ **ทีมกรม** (อัปเดตข้อมูลรายวัน) ไม่ต้องมีความรู้ด้านเทคนิค
ขอลิงก์เว็บ และรหัสผ่านสำหรับเผยแพร่ (เฉพาะทีมกรม) ได้จากทีม operate

## ข้อมูลบนหน้าเป็นของวันไหน

ทุกแท็บมี 2 จุดที่ควรดู:

- **"ข้อมูล ณ ช่วงวันที่ …"** ใต้หัวข้อใหญ่: ช่วงวันที่ของรายงาน อ่านมาจากไฟล์ CSV
- **บรรทัดข้างปุ่มอัปโหลด CSV:** บอกว่ากำลังดูข้อมูลชุดไหน

| ข้อความที่เห็น | ความหมาย |
|---|---|
| `ข้อมูลล่าสุด เผยแพร่ 5 พ.ย. 2569 09:30 · ชื่อไฟล์` | ข้อมูลที่ทีมกรมเผยแพร่ล่าสุด ทุกคนเห็นชุดเดียวกัน |
| `ข้อมูลตั้งต้น · ชื่อไฟล์` | ยังไม่เคยมีการเผยแพร่ หรือระบบเผยแพร่มีปัญหา (แจ้งทีม operate) |
| `ชื่อไฟล์ · ตัวอย่าง ยังไม่ได้เผยแพร่` | ไฟล์ที่คุณอัปโหลดเอง คนอื่นไม่เห็น รีเฟรชหน้าแล้วกลับไปเป็นข้อมูลล่าสุด |

## สำหรับผู้บริหาร: ดูข้อมูล

1. เปิดลิงก์เว็บ แล้วเลือกแท็บด้านบน
   - **อุทกภัยรายจังหวัด:** ตัวเลขสรุป แผนที่จังหวัดที่ได้รับผลกระทบ และตารางรายจังหวัด
   - **สรุปคำร้องทุกประเภทภัย:** กราฟคำร้องตามประเภทภัยและภาค การช่วยเหลือ ความเสียหาย และ 10 จังหวัดที่มีคำร้องมากที่สุด
2. แท็บอุทกภัย: ชี้หรือแตะจังหวัดบนแผนที่เพื่อดูตัวเลข หรือกดแถวในตารางเพื่อดูว่าจังหวัดนั้นอยู่ตรงไหนบนแผนที่ บนมือถือเลือกจังหวัดจากรายการได้
3. แท็บทุกประเภทภัย: ชี้หรือแตะแท่งกราฟเพื่อดูตัวเลข ตัวเลขทั้งหมดมีในตารางท้ายหน้าด้วย
4. เปิดจากมือถือได้ หน้าจะจัดรูปแบบให้อ่านง่ายเอง

ถ้าเปิดหน้าค้างไว้นาน ให้**รีเฟรช**เพื่อดูข้อมูลที่เผยแพร่ใหม่ ผู้บริหารไม่ต้องกดอัปโหลด ถ้าเผลออัปโหลดไป ให้รีเฟรชหน้า

## สำหรับทีมกรม: อัปเดตข้อมูลรายวัน

ใช้ไฟล์ export **"รายงานจำนวนคำร้องและความเสียหาย"** จากระบบพ้นภัย ไม่ต้องแก้ไฟล์ก่อนอัปโหลด

1. เปิดลิงก์เว็บ จะอยู่แท็บไหนก็ได้ เพราะทุกแท็บใช้ข้อมูลชุดเดียวกัน
2. กด **อัปโหลด CSV** แล้วเลือกไฟล์ ถ้ามีหลายไฟล์ ให้กด Ctrl (บน Mac ใช้ Cmd) ค้างไว้แล้วคลิกเลือกทุกไฟล์ในหน้าต่างเดียว
3. **ตรวจข้อมูลก่อนเผยแพร่:** ข้างปุ่มจะขึ้นว่า "ตัวอย่าง ยังไม่ได้เผยแพร่" ตอนนี้มีแค่คุณที่เห็น ให้ดูช่วงวันที่ และเทียบยอดรวม 1–2 ค่ากับไฟล์ใน Excel
4. กด **เผยแพร่** ใส่รหัสผ่าน แล้วกดเผยแพร่อีกครั้ง
5. เมื่อขึ้นข้อความ "เผยแพร่แล้ว" ข้างปุ่มจะเปลี่ยนเป็น "ข้อมูลล่าสุด เผยแพร่ …" ผู้บริหารจะเห็นข้อมูลชุดนี้ในทุกแท็บเมื่อเปิดหรือรีเฟรชหน้า ภายในไม่เกิน 1 นาทีหลังเผยแพร่

ควรรู้:
- **เผยแพร่แต่ละครั้งแทนที่ข้อมูลเดิมทั้งหมด** ไม่ได้ต่อท้าย ถ้ารายงานแบ่งเป็นหลายไฟล์ ต้องเลือกทุกไฟล์พร้อมกันในการอัปโหลดครั้งเดียว
- **อย่าเลือกไฟล์ที่มีข้อมูลซ้ำกัน** เช่น ไฟล์เต็มกับไฟล์บางส่วนของวันเดียวกัน ตัวเลขจะถูกนับซ้ำ
- **ถ้าเผยแพร่ไฟล์ผิด** ให้อัปโหลดไฟล์ที่ถูกต้องแล้วเผยแพร่ซ้ำ ชุดใหม่จะแทนที่ทันที ระบบเก็บประวัติทุกครั้งไว้ให้ทีม operate ตรวจย้อนหลังได้
- **ถ้าอัปโหลดผิดแต่ยังไม่ได้กดเผยแพร่** รีเฟรชหน้าได้เลย ไม่มีผลกับคนอื่น
- **อย่าส่งต่อรหัสผ่าน** ถ้าคิดว่ารหัสหลุด ให้แจ้งทีม operate เปลี่ยนรหัส
