# Dashboard พ้นภัย

Dashboard บน Vercel: หน้าเว็บเป็น HTML ล้วน ไม่ต้อง build มี API เล็กๆ 2 ตัวสำหรับแชร์ข้อมูล (`api/`)
`index.html` เป็นแถบแท็บ แต่ละแท็บคือ dashboard หนึ่งหน้าในโฟลเดอร์ `dashboards/`

| ใคร | ทำอะไร | อ่าน |
|---|---|---|
| ผู้บริหาร | เปิดเว็บ ดูข้อมูลชุดล่าสุดในทุกแท็บ | [`docs/USER-GUIDE.md`](docs/USER-GUIDE.md) |
| ทีมกรม | อัปโหลด CSV รายวัน ตรวจข้อมูล แล้วกด **แชร์** | [`docs/USER-GUIDE.md`](docs/USER-GUIDE.md) |
| ทีม operate | พัฒนาและเพิ่ม dashboard, ดูแล Vercel | ไฟล์นี้ และ [`docs/AI-PROMPTS.md`](docs/AI-PROMPTS.md) |

| แท็บ | ไฟล์ | แสดงอะไร |
|---|---|---|
| อุทกภัยรายจังหวัด | `dashboards/flood.html` | แผนที่ ตาราง และสรุปรายจังหวัด เฉพาะอุทกภัย |
| สรุปคำร้องทุกประเภทภัย | `dashboards/disasters.html` | กราฟคำร้องตามประเภทภัยและภาค, การช่วยเหลือ, ความเสียหาย, 10 จังหวัดสูงสุด |

กฎของโปรเจกต์สำหรับ AI อยู่ใน [`AGENTS.md`](AGENTS.md) (`CLAUDE.md` ดึงจากไฟล์นี้)

## หลักการทำงาน

1. **แท็บ:** `index.html` แสดงแถบแท็บจากรายการ `DASHBOARDS` แต่ละแท็บเปิด `dashboards/<ชื่อ>.html` ใน iframe ของตัวเอง แท็บจะถูกโหลดเมื่อเปิดครั้งแรก และข้อมูลยังอยู่เมื่อสลับแท็บ
2. **ข้อมูลตอนเปิดหน้า:** ทุกแท็บเรียก `connectCSV()` ใน `dashboards/shared/csv.js` ซึ่งขอ `/api/latest` ก่อน
   - **ถ้ามีข้อมูลที่แชร์:** ได้ไฟล์ CSV ชุดล่าสุดกลับมา
   - **ถ้ายังไม่เคยแชร์ หรือไม่มี API (รันในเครื่อง):** โหลดไฟล์ใน `data/` (`DEFAULT_CSV_FILES`) แทน
   - **ถ้าเปิดด้วยการดับเบิลคลิก (`file://`):** โหลดไม่ได้ทั้งสองทาง หน้าจะว่าง
3. **คำนวณและแสดงผล:** แต่ละหน้าอ่าน CSV ด้วยฟังก์ชันใน `csv.js` แล้วคำนวณเองทั้งหมดในเบราว์เซอร์ ไม่มีฐานข้อมูล
4. **อัปโหลด:** ไฟล์ที่อัปโหลดถูกอ่านในเบราว์เซอร์ของคนนั้นเท่านั้น (ตัวอย่าง) และมีปุ่ม **แชร์** ขึ้นมา
5. **แชร์:** ส่งไฟล์ไป `/api/publish` API ตรวจว่าเป็นไฟล์รายงาน (มีแถวหัวคอลัมน์ `province`) และตรวจรหัสผ่านถ้าตั้ง `PUBLISH_PASSWORD` ไว้ จากนั้นเก็บไฟล์ลง Vercel Blob แบบ private ในโฟลเดอร์ `published/<เวลา>/` แล้วเขียน `latest.json` ชี้ไปที่ชุดนั้น
   - **ลำดับการเขียน:** เขียน `latest.json` เป็นขั้นสุดท้าย ผู้ชมจึงไม่เห็นข้อมูลที่เขียนไม่ครบ
   - **ประวัติ:** ชุดเก่ายังเก็บไว้ ไม่ถูกลบ
6. **ผู้ชมคนอื่น:** เห็นชุดใหม่เมื่อเปิดหรือรีเฟรชหน้า ภายในไม่เกิน 1 นาที (`/api/latest` ให้ Vercel cache คำตอบไว้ 60 วินาที เพื่อประหยัดโควตา) ทุกแท็บใช้ข้อมูลชุดเดียวกัน dashboard ใหม่จึงต้องอ่าน CSV รูปแบบเดียวกัน

หน้าเว็บสลับเป็นแบบมือถือเองเมื่อจอกว้างไม่เกิน 800px

## เพิ่ม dashboard ใหม่ (เพิ่มแท็บ)

มี 2 แบบ:

| | แบบการ์ด + ตาราง | แบบออกแบบเอง |
|---|---|---|
| เริ่มจาก | copy `dashboards/_template.html` | สร้างไฟล์ HTML ใหม่ ดูโครงจาก `dashboards/disasters.html` |
| แก้อะไร | แค่ค่าใน `renderDashboard({...})` ไม่ต้องเขียนโค้ด | เขียน HTML/CSS/JS เอง (หรือให้ AI ทำ ดู `docs/AI-PROMPTS.md`) |
| หน้าตา | เหมือนกันทุกหน้า (`shared/simple-dashboard.css`) | อิสระ เช่น กราฟ แผนที่ |
| ตัวอย่าง | `_template.html` (สรุปคำร้องอุทกภัยรายภาค) | `disasters.html`, `flood.html` |

ทั้งสองแบบเชื่อมข้อมูลด้วย `connectCSV()` ใน `dashboards/shared/csv.js` จึงได้ข้อมูลล่าสุดและปุ่มแชร์เหมือนทุกแท็บ จากนั้นเพิ่ม 1 บรรทัดในรายการ `DASHBOARDS` ที่ `index.html`

```js
const DASHBOARDS = [
  { id: 'flood',     title: 'อุทกภัยรายจังหวัด', file: 'dashboards/flood.html' },
  { id: 'disasters', title: 'สรุปคำร้องทุกประเภทภัย',  file: 'dashboards/disasters.html' },
  { id: 'region',    title: 'สรุปรายภาค',        file: 'dashboards/region.html' },   // เพิ่มบรรทัดนี้
];
```

ตัวเลือกของแบบการ์ด + ตาราง (คำอธิบายเต็มอยู่ใน `_template.html`):
- `title`, `eyebrow`: หัวข้อของหน้า
- `headerFirstColumn`: ช่องแรกของแถวหัวคอลัมน์ใน CSV (ไฟล์รายงานพ้นภัยใช้ `province`)
- `filter`: เลือกเฉพาะแถวที่ต้องการ เช่น `row => row.disaster === 'อุทกภัย'`
- `groupBy`: รวมแถวตามคอลัมน์ เช่น `'region'` ได้ตารางรายภาค
- `sortBy`: เรียงตารางจากมากไปน้อย
- `kpis`: การ์ดตัวเลขด้านบน (ผลรวมของคอลัมน์ หรือจำนวนแถว)
- `columns`: คอลัมน์ในตาราง (ข้อความ, ตัวเลข หรือนับจำนวนค่าที่ไม่ซ้ำ)

ข้อควรรู้:
- **ทดสอบก่อนเพิ่มแท็บ:** รัน `python3 -m http.server` แล้วเปิด `dashboards/<ชื่อ>.html` ตรงๆ จะเห็นข้อมูลตั้งต้นทันที
- **ต้องเป็น CSV รูปแบบเดียวกับรายงานนี้:** ข้อมูลที่แชร์ใช้ร่วมกันทุกแท็บ ถ้าต้องการ dashboard ที่ใช้ไฟล์รูปแบบอื่น ต้องแยกช่องแชร์เพิ่ม (แก้ `api/` และ `csv.js`)
- **commit ด้วยบัญชี phonphai เท่านั้น:** Vercel แผน Hobby ไม่ deploy commit ของคนอื่นใน repo แบบ private
- **แต่ละหน้าแยกกันใน iframe:** CSS และ JS ของหน้าหนึ่งไม่กระทบหน้าอื่น

## รูปแบบไฟล์ CSV

ทุกแท็บใช้ไฟล์ export "รายงานจำนวนคำร้องและความเสียหาย" ตามตัวอย่าง `data/md_flood_report.csv` กฎด้านล่างเป็นของแท็บอุทกภัยรายจังหวัด (`dashboards/flood.html`) แท็บอื่นใช้กฎการอ่านไฟล์และการรวมหลายไฟล์แบบเดียวกัน แต่ไม่กรองเฉพาะอุทกภัย

```
รายงานจำนวนคำร้องและความเสียหาย,,,...
ข้อมูลตั้งแต่วันที่ 1 ตุลาคม 2569 ถึงวันที่ 15 ตุลาคม 2569,,,...
province,disaster,all_issue,all_issue_warning,all_issue_need_help,...,region
จ.กำแพงเพชร,อุทกภัย,1017,10,1007,...,ภาคกลาง
```

- **แถวหัวคอลัมน์** คือแถวที่ช่องแรกเป็น `province` แถวก่อนหน้านั้นเป็นหัวรายงาน
- **ช่วงวันที่** อ่านจากบรรทัด "ข้อมูลตั้งแต่วันที่ … ถึงวันที่ …" (ใช้ชื่อเดือนภาษาไทยเต็ม ปี พ.ศ.)
- **คอลัมน์ที่ต้องมี:** `province`, `disaster`, `region`, `all_issue_warning`, `all_issue_need_help`, `all_household`, `help_household`, `vuner_count` คอลัมน์อื่นไม่ถูกใช้
- **ใช้เฉพาะแถวที่ `disaster` = `อุทกภัย`** แถวของภัยอื่นจะถูกข้าม
- **ค่าว่าง:** `null`, ช่องว่าง หรือ `-` ถือว่าไม่มีข้อมูล และแสดงเป็น `-`
- **ชื่อภาค** ต้องตรงกับ `ภาคเหนือ`, `ภาคกลาง`, `ภาคตะวันออก`, `ภาคตะวันตก`, `ภาคตะวันออกเฉียงเหนือ`, `ภาคใต้` ถึงจะได้สีบนแผนที่
- **Encoding:** อ่านได้ทั้ง UTF-8 และ Windows-874 (ไฟล์ที่บันทึกจาก Excel ภาษาไทย)

## การรวมหลายไฟล์

- **รวมแถวจากทุกไฟล์:** จังหวัดที่อยู่ในหลายไฟล์จะถูกบวกรวม ใช้ได้ทั้งไฟล์ที่แยกตามแถว (เช่นแยกตามภาค) และไฟล์ที่แยกตามช่วงเวลา
- **ผู้เปราะบาง** ไม่บวกรวม ใช้ค่าสูงสุดของจังหวัดนั้น เพราะเป็นตัวเลขประจำจังหวัด
- **ช่วงวันที่** ใช้วันเริ่มที่เร็วที่สุดถึงวันสิ้นสุดที่ช้าที่สุด เช่น 1–15 ต.ค. + 16–31 ต.ค. แสดงเป็น 1–31 ต.ค. ถ้าช่วงไม่ต่อกันก็ยังแสดงเป็นช่วงเดียว
- **ไม่ตรวจไฟล์ซ้ำ:** ถ้าเลือกไฟล์ที่มีข้อมูลซ้ำกัน ตัวเลขจะถูกนับสองครั้ง

## วิธีคำนวณ

| ค่าที่แสดง | ที่มา |
|---|---|
| คำร้อง | `all_issue_warning` + `all_issue_need_help` |
| ร้อยละช่วยเหลือ | `help_household` ÷ `all_household` × 100 (คำนวณใหม่ ไม่ใช้คอลัมน์ `percent_help`) |
| ผู้เปราะบาง | `vuner_count` ของแต่ละจังหวัด ถ้าจังหวัดเดียวกันมีหลายแถวจะใช้ค่าสูงสุด ไม่บวกซ้ำ |
| ลำดับในตาราง | จำนวนคำร้องมากไปน้อย ถ้าเท่ากันเรียงตามครัวเรือนที่ได้รับผลกระทบ |

ป้ายชื่อบนแผนที่แสดงเฉพาะ 6 จังหวัดที่มีคำร้องมากที่สุด เพื่อไม่ให้ป้ายซ้อนกัน จังหวัดอื่นยังมีสีและกดดูข้อมูลได้

## ไฟล์ทดสอบ

ไฟล์ใน `source/` เป็นข้อมูลรายงานจริงและไฟล์ที่สร้างจากข้อมูลจริง จึง**ไม่ได้เอาขึ้น git** (อยู่ใน `.gitignore`) ถ้า clone repo ไปแล้วไม่มีไฟล์เหล่านี้ ให้ขอจากทีม แล้ววางไว้ที่ `source/` ในเครื่อง

แท็บ **อุทกภัยรายจังหวัด**:

| ไฟล์ | จังหวัด | แจ้งภัย / ร้องขอ | ครัวเรือนได้รับผลกระทบ | ช่วยเหลือแล้ว | ร้อยละ | ผู้เปราะบาง |
|---|---|---|---|---|---|---|
| `source/md_flood_report.csv` (ไฟล์จริง 1–15 ต.ค. 2569) | 32 | 129 / 1,815 | 173,808 | 137,465 | 79.09% | 228,369 |
| `source/md_flood_report_test.csv` (ไฟล์ทดสอบ 16–31 ต.ค. 2569) | 31 | 136 / 2,247 | 192,354 | 165,317 | 85.94% | 220,513 |
| `source/md_flood_report_part1.csv` | 23 | 124 / 1,805 | 173,484 | 137,382 | 79.19% | 146,247 |
| `part1` + `part2` (เลือกพร้อมกัน) | 32 | 129 / 1,815 | 173,808 | 137,465 | 79.09% | 228,369 |
| `md_flood_report.csv` + `md_flood_report_test.csv` (เลือกพร้อมกัน, 1–31 ต.ค.) | 33 | 265 / 4,062 | 366,162 | 302,782 | 82.69% | 237,469 |

ไฟล์ทดสอบสร้างจากไฟล์จริงโดยปรับค่าดังนี้: ร้องขอความช่วยเหลือ +20%, ครัวเรือนได้รับผลกระทบ +10%, ช่วยเหลือแล้วเพิ่มขึ้น (ไม่เกินครัวเรือนที่ได้รับผลกระทบ), ตัด จ.ชลบุรี และ จ.เพชรบูรณ์ ออก และเพิ่ม จ.เชียงราย (ภาคเหนือ)
แท็บ **สรุปคำร้องทุกประเภทภัย** เมื่ออัปโหลด `md_flood_report.csv` (หรือ part1 + part2) ต้องได้:
- **ภาพรวม:** 8 ประเภทภัย, 36 จังหวัด, คำร้องรวม 1,973 (แจ้งภัย 140 · ร้องขอ 1,833), ครัวเรือนได้รับผลกระทบ 178,565, ช่วยเหลือแล้ว 142,202 (79.6%)
- **รายประเภทภัย:** อุทกภัย 1,944 คำร้อง 32 จังหวัด
- **รายภาค:** ภาคกลาง 1,843 คำร้อง
- **ความเสียหาย (ช่วยเหลือแล้ว / เสียหาย):** อาคาร 11,728 / 17,691, การเกษตร 4,000 / 8,080, โครงสร้างพื้นฐาน 2 / 9
- **จังหวัดคำร้องสูงสุด:** กำแพงเพชร 1,018

`md_flood_report_part1.csv` และ `md_flood_report_part2.csv` คือไฟล์จริงที่แบ่งแถวข้อมูลเป็นสองครึ่ง (หัวรายงานเหมือนกัน) เลือกสองไฟล์พร้อมกันแล้วต้องได้ตัวเลขเท่ากับไฟล์จริงทุกช่อง
อัปโหลดแต่ละกรณีแล้วตัวเลขบนหน้าต้องตรงกับตารางนี้

## แผนที่

ขอบเขตจังหวัดโหลดจาก GeoJSON ตามลำดับใน `GEOJSON_URLS` (ใน `dashboards/flood.html`) ลองไฟล์ `thailand-provinces.geojson` ที่วางข้าง `index.html` ก่อน ถ้าไม่มีจะดึงจาก CDN จึงต้องต่ออินเทอร์เน็ต
ถ้าไม่อยากพึ่ง CDN ให้วางไฟล์นั้นไว้ข้าง `index.html` (ใช้ได้เมื่อเปิดผ่านเว็บหรือ local server เท่านั้น)

```bash
python3 -m http.server 8000
# หรือ
npx serve .
```

## Deploy บน Vercel

1. push ขึ้น GitHub แล้ว Import ใน Vercel (Framework Preset: Other ไม่ต้องมี build command) ทุกครั้งที่ push ขึ้น `main` จะ deploy ให้อัตโนมัติ
2. **เชื่อม Blob store** (ทำครั้งเดียว): Vercel project → Storage → Create → Blob
   - ถ้าให้เลือกการเข้าถึง ให้เลือก **Private** (API เก็บและอ่านไฟล์แบบ `access: 'private'`)
   - กดเชื่อมกับโปรเจกต์นี้ Vercel จะเพิ่ม `BLOB_READ_WRITE_TOKEN` ให้เอง
3. **รหัสผ่านแชร์ (ไม่บังคับ):** ตอนนี้ยังไม่ได้ตั้ง ใครเปิดเว็บก็กดแชร์ได้ ถ้าต้องการจำกัดให้เฉพาะทีมกรม ให้ไปที่ Settings → Environment Variables → เพิ่ม `PUBLISH_PASSWORD` หน้าต่างยืนยันจะมีช่องใส่รหัสขึ้นมาเอง ไม่ต้องแก้โค้ด จากนั้นส่งรหัสให้ทีมกรมทางช่องทางที่ปลอดภัย
   - **ความเสี่ยงถ้าไม่ตั้งรหัส:** ใครมีลิงก์ก็แชร์ทับข้อมูลที่ผู้บริหารเห็นได้ ถ้ามีคนยิงแชร์รัวๆ อาจใช้โควตาฟรีของ Blob หมด แล้ว Blob ถูกปิด 30 วัน
   - **ถ้าข้อมูลถูกทับผิด:** แชร์ไฟล์ที่ถูกต้องซ้ำ ชุดเก่ายังอยู่ใน `published/`
4. Redeploy หนึ่งครั้งเพื่อให้ค่าใหม่มีผล (Deployments → … → Redeploy หรือ push อะไรก็ได้)

**เปลี่ยนหรือยกเลิกรหัสผ่าน:** แก้หรือลบ `PUBLISH_PASSWORD` แล้ว Redeploy

**ใครเปิดเว็บได้:** ทุกคนที่มีลิงก์เปิดเว็บและเห็นข้อมูลล่าสุดได้ ถ้าต้องการจำกัดให้เฉพาะผู้บริหาร ดูที่ Settings → Deployment Protection (ตัวเลือกขึ้นกับแผนของบัญชี)

**ทดสอบในเครื่อง:** `python3 -m http.server` ทดสอบได้ทุกอย่าง ยกเว้นการแชร์ ซึ่งต้องใช้ `vercel dev` ที่ link กับโปรเจกต์และมี token ของ Blob

```
index.html                         แถบแท็บ + รายการ DASHBOARDS

api/latest.js                      GET: ส่งข้อมูลชุดล่าสุดที่แชร์ให้ทุกแท็บ
package.json                       dependency ของ api/ (@vercel/blob)
AGENTS.md                          กฎของโปรเจกต์สำหรับ AI (CLAUDE.md ดึงจากไฟล์นี้)
docs/USER-GUIDE.md                 คู่มือใช้งาน: ผู้บริหาร และทีมกรม (อัปเดต/แชร์ข้อมูล, ปัญหาที่พบบ่อย)
docs/AI-PROMPTS.md                 คู่มือทีม operate: ใช้ AI สร้าง/แก้ dashboard
dashboards/
  flood.html                       แท็บอุทกภัยรายจังหวัด (แผนที่ ตาราง สรุป)
  disasters.html                   แท็บสรุปคำร้องทุกประเภทภัย (ออกแบบเอง: กราฟ meter ตาราง)
  _template.html                   แม่แบบสำหรับ dashboard ใหม่ (ไม่ได้อยู่ในแท็บ)
  shared/csv.js                    อ่าน CSV, encoding, ช่วงวันที่, โหลดข้อมูลล่าสุด, ปุ่มแชร์ (connectCSV) ใช้ร่วมกันทุกหน้า
  shared/simple-dashboard.js       สร้างหน้าการ์ด + ตาราง จากค่าใน renderDashboard({...})
  shared/simple-dashboard.css      หน้าตาของหน้าที่สร้างจาก simple-dashboard.js
data/                              ข้อมูลตั้งต้น ใช้เมื่อยังไม่เคยแชร์ หรือรันในเครื่อง (ขึ้นเว็บด้วย)
source/                            ไฟล์ CSV ตัวอย่างและไฟล์ทดสอบ (ไม่อยู่ใน git ดู .gitignore; หน้าเว็บไม่ได้อ่านเอง ใช้สำหรับกดอัปโหลด)
```
